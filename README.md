# ICT Final Project
The purpose of this repository is to hold all the files related to the Final Project for the subject Introduction to Information and Communication Technology (CL-1000) at FAST-NUCES.
Below is a brief description of every file included in this repository:

- index.html: The code for the homepage and basic interface of the project, this contains links to all of the other pages, as well as links to the JS and CSS files.
- brwose.html: This is the code for the page that allows you to view all posted events.
- post.html: This is the code for the page that allows you to add your own event (Implementation requires a backend server and since this is a front end project, it doesn't actually add the event, just shows implementation of a form).
