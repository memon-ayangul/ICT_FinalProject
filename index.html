UniPulse puts society orientations, competitions, seminars and social events from FAST Karachi in one place.

What is UniPulse?

UniPulse is an unofficial events board made by students for students at FAST-NUCES Karachi.

Events usually get shared in social media posts, class groups and society announcements, so it is easy to miss them. UniPulse collects them on one website so you can see what is coming up.

What you can do here

  • See upcoming events from societies, departments and outside organizations
  • Search events by name and filter them by category
  • Open any event to read its date, time, location and description
  • Post your own event from the Post Your Event page
